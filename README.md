# UTS Pemesanan Makanan

## Deskripsi Proyek

Aplikasi Pemesanan Makanan merupakan prototipe sistem pemesanan makanan yang terdiri dari dua antarmuka, yaitu Dashboard Web untuk Admin dan Mobile Application untuk pengguna.

Aplikasi ini dibuat untuk memenuhi kebutuhan Ujian Tengah Semester (UTS) menggunakan Flutter. Sistem menggunakan dummy data dan belum menggunakan database.

## Fitur Aplikasi

### 1. Dashboard Web Admin

Dashboard Web digunakan oleh admin untuk mengelola data dan melihat informasi pemesanan.

Fitur yang tersedia:
- Login Admin
- Dashboard utama
- Statistik data pesanan
- Tampilan data pesanan dalam bentuk tabel
- Pengelolaan menu makanan
- Menambahkan menu makanan
- Menghapus menu makanan

### 2. Mobile Application

Mobile Application digunakan oleh pengguna untuk melakukan pemesanan makanan.

Fitur yang tersedia:
- Login pengguna
- Halaman utama
- Menampilkan daftar menu makanan
- Form pemesanan makanan
- Input jumlah pesanan
- Menampilkan hasil atau struk pemesanan
- Validasi input sederhana

## Teknologi dan Package yang Digunakan

- Flutter
- Dart
- Material Design
- Dummy Data
